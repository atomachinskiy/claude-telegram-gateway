# tg-gateway на маке — несколько ботов/сессий (инструкция для Claude на маке)

Каждый «инстанс» = **один бот + одна tmux-сессия Claude**, связанные общей папкой
`STATE_DIR = ~/.claude/channels/<name>`. Демоны и сессии не конфликтуют — всё
разнесено по этой папке (лок, inbox/outbox, токен — пер-папку). Боты у Андрея
уже заведены в @BotFather, токены есть. Ядро мультиинстанс умеет из коробки —
ничего пересобирать не нужно, помогает только хелпер `bin/tgw`.

## Разово на машину

1. Репо уже в гите — склонировать/обновить: `git -C ~/tg-gateway pull` (или `git clone <url> ~/tg-gateway`).
2. **`--channels` — research preview.** Локальный мост `telegram-local` надо разрешить в managed-settings:
   - macOS путь (проверь точный — на сервере это `/etc/claude-code/managed-settings.json`):
     `~/Library/Application Support/ClaudeCode/managed-settings.json`
   - Добавить `telegram-local` в allowlist каналов (формат — как whitelisting на сервере). Разово, не на каждый инстанс.
3. Нужны: `node` (идёт с Claude Code) или `bun`, и `tmux`.

## На каждый бот (токен от @BotFather)

```
~/tg-gateway/bin/tgw add <name> <bot-token>   # пейринг (напиши боту /start) + демон под LaunchAgent, живёт 24/7
~/tg-gateway/bin/tgw up  <name>               # поднимает сессию и подключает (tmux attach)
```

- `<name>` — короткое имя инстанса, `[a-z0-9-]`, обычно по проекту (kontur, billing…).
- `tgw list` — статусы всех (демон / сессия).
- `tgw rm <name>` — убрать инстанс (стейт-папку оставляет).
- Выйти из сессии не убивая её: `Ctrl-b d` (tmux detach). Вернуться: `tgw up <name>`.

## Что даёт

- С телефона по каждому боту работают `/status` `/screen` `/restart` `/model` — рулят **именно своей** сессией.
- Демон ловит сообщения и шлёт **auth/brain-алерты** (v1.1.0), даже когда сессия легла: разлогин (401) и «мозг недоступен» больше не уходят в тишину.

## Правила

- **Один бот-токен = один инстанс.** Telegram держит один поллер на токен; второй → HTTP 409. Хелпер кладёт токен в свою папку, не переиспользуй один токен на два имени.
- Имя инстанса строго `[a-z0-9-]` (идёт в имя tmux / LaunchAgent / путь).
- Демон — всегда-живая часть (LaunchAgent, RunAtLoad+KeepAlive). tmux-сессия (мозг) после ребута сама не встаёт — подними `tgw up <name>`.
