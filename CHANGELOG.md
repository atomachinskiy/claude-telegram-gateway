# Changelog

## 1.2.0 — 2026-10-13
Синхронизация публичной версии с рабочей веткой (июль–сентябрь 2026).

**Для всех установок (Windows, Mac, Linux):**
- Формат ответа `rich`: бот шлёт Bot API rich message (`sendRichMessage`) с обычным GitHub-markdown: таблицы, заголовки, списки, цитаты. До 32 тыс. знаков одним сообщением; если Telegram не принял разметку, ответ уходит простым текстом. Правка такого сообщения через `editMessageText`.
- Если прислали файл больше 20 МБ, бот сразу говорит отправителю, что скачать его не может (лимит облачного Bot API), а не молчит.
- `TELEGRAM_API_ROOT` и `TELEGRAM_DL_LIMIT_MB`: можно подключить свой локальный Bot API сервер и поднять лимит скачивания до 2 ГБ.
- Темы форум-супергрупп: у каждой темы свой инбокс, ответ уходит в ту же тему (`message_thread_id`), allowlist пользователей в группе.
- `install-windows.ps1`: вызовы `node` и `claude` больше не обрывают скрипт в Windows PowerShell 5.1, когда они пишут в stderr (так бывает, если скрипт запускает ИИ-ассистент). Проверка, что сопряжение с ботом завершилось и плагин зарегистрирован.

**Только для серверного режима (сессия Claude в tmux):**
- `/model`: живой каталог моделей (`GET /v1/models`, кэш 30 мин, резервный список), кнопка «· 1M» для моделей с окном 1M (`TG_MODELS_1M=0` прячет).
- `/effort` и кнопка «⚡ Effort» в `/menu`: low / medium / high / xhigh / max / auto на лету.
- Подпись сессии в панели задаётся `TG_SESSION_LABEL`, имя tmux-сессии `CLAUDE_TMUX` (по умолчанию `claude`).
- Перед рестартом зачищаются осиротевшие фоновые форки сессии с `--channels`.

## 1.1.0 — 2026-06-25
